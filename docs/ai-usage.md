# AI 使用说明

本项目使用 AI 编程助手辅助需求拆解、代码编写、测试设计和文档整理。工程交付包含源代码、可重建 fixture、自动检查及已运行演示，供评审独立复现。

运行时的默认 demo 不调用模型：新闻与行情为合成数据，PDF 响应为固定样例，但仍实际解析 PDF 并执行证据校验。真实 PDF 模式通过配置的模型抽取结构化 JSON；新闻摘要与日报渲染采用确定性摘录和模板。

检查重点包括原文引用、单位换算、Resources/Reserves、JORC/NI 43-101、日期、行情合约和失败状态。通过单元测试不等于完成真实矿业报告精度验证；未运行的真实模型、真实行情和客户端 UI 项目会在验证记录中如实列出。

提交者应在面试前实际运行项目，并能够解释任务计划、MCP 生命周期、模型调用、价格数据契约和各类降级行为。
